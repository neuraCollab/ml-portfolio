# Kaggle Titanic 

- **Задача**: бинарная классификация выживаемости пассажиров.
- **Два решения**:
  - **TensorFlow Decision Forests (TF-DF) — Gradient Boosted Trees** (`titanic_tf.py`)
  - **Scikit‑learn — RandomForestClassifier** (`titnic.py`)

### Что использовано и почему

- **Деревья решений для табличных данных**: устойчивы к разномасштабным признакам, хорошо работают “из коробки”, мало требуют нормализации.
- **TF‑DF (GBT)**:
  - Бустинг деревьев с обличными сплитами и тюнингом гиперпараметров.
  - Простая обработка текста: токенизация `Name` через `tf.strings.split`, разбор `Ticket` на `Ticket_number` и `Ticket_item`.
  - Посмотреть че даст по разным `random_seed` для стабилизации предсказаний.
- **RandomForest**:
  - Базовая, быстрая и надёжная классика для табличных данных.
  - Минимальные признаки (`Pclass, Sex, SibSp, Parch`) + `pd.get_dummies` для категорий.
  - Настроенные ключевые гиперпараметры (глубина, число деревьев, пороги разбиений).

### Как запустить

- Требуемые файлы: `train.csv`, `test.csv` в корне проекта.

TF‑DF (создаст `submission.csv` в `/kaggle/working` внутри каггл-окружения):
```bash
python titanic_tf.py
```

Scikit‑learn (создаст `submission.csv` в корне проекта):
```bash
python titnic.py
```

Зависимости (минимум):
```bash
pip install pandas numpy scikit-learn tensorflow tensorflow-decision-forests
```

### Альтернативы и когда что выбирать

- **Когда GBT (TF‑DF, XGBoost/LightGBM/CatBoost)**:
  - Табличные данные с миксом числовых/категориальных фичей.
  - Нужен top‑score при умеренном времени обучения.
  - Есть смысл в тонком тюнинге гиперпараметров и/или использовании текстовых токенов как категорий.
- **Когда RandomForest**:
  - Быстрый бейзлайн, устойчив к шуму, мало тюнинга.
  - Малый риск переобучения, понятная интерпретация feature importance.
- **Когда по‑другому**:
  - **CatBoost/LightGBM/XGBoost**: часто дадут сопоставимый или лучший результат на табличных данных, особенно с категориальными признаками.
  - **Логистическая регрессия/линейные модели**: если признаков много и они хорошо подготовлены (нормализация, полиномиальные/взаимодействия), нужен быстрый и интерпретируемый результат.
  - **Нейросети**: редко оправданы для классического табличного Titanic, полезны при наличии богатого текста/изображений/мультимодальности.

### Почему именно так

- Titanic — классическая табличная задача, где **градиентный бустинг** и **случайный лес** обычно доминируют. Добавленная **токенизация `Name`** и разбор `Ticket` дают лёгкое расширение признаков без сложного NLP. Тюнинг TF‑DF и энсемблирование по `seed` повышают стабильность и качество.
