## Портфолио-проект: Практика со scikit-learn (Supervised Learning)

Этот репозиторий — моя коллекция практических имплементаций и мини-исследований по методам обучения с учителем на базе библиотеки `scikit-learn`. Проект демонстрирует мои навыки классического ML: от линейных моделей и регуляризации до дискриминантного анализа и SVM, включая сравнение методов и интерпретацию результатов.

В каждой тематической папке есть собственная документация (Readme.md/описания) и самостоятельный исполняемый код с примерами запуска и визуализациями. Так работодатель может быстро оценить глубину проработки каждой темы отдельно.

### Ключевые навыки, которые демонстрирует проект
- **Python / scikit-learn / numpy / matplotlib**: подготовка данных, построение и обучение моделей, визуализация.
- **Линейные модели**: регрессия и классификация, регуляризация (L1/L2/ElasticNet), отбор признаков.
- **Оптимизация**: SGD, Passive-Aggressive, Orthogonal Matching Pursuit.
- **Байесовские подходы**: BayesRidge, ARD Regression.
- **Обобщённые линейные модели**: работа с различными функциями связи.
- **Дискриминантный анализ**: сравнение LDA и PCA, влияние на разделимость классов.
- **Методы ядрового сглаживания/гребневая регрессия с ядрами**.
- **SVM**: классификация, гиперпараметры, визуализация границ решений.
- **Оценка качества**: метрики, кросс-валидация, отчёты классификации, сравнение подходов.

### Структура репозитория (основные темы)
- `supervised-learning/`
  - `linear/` — Линейные методы:
    - `Least Squares/` — МНК и неотрицательные МНК.
    - `Ridge/` — гребневая регрессия, классификатор Ridge, CV и отчёты.
    - `Lasso/` — Lasso, LassoLars (CV/IC), Multi-Task Lasso.
    - `Elastic Net/` — ElasticNet.
    - `LARS/` — Least Angle Regression.
    - `OMP/` — Orthogonal Matching Pursuit (+ анализ ошибки/разреженности).
    - `PA/` — Passive-Aggressive.
    - `Sgd/` — стохастический градиентный спуск (SGD) для задач клф/рег.
    - `Logistic/` — логистическая регрессия (в т.ч. на MNIST), метрики и визуализации.
    - `Generalized LM/` — обобщённые линейные модели.
    - `Quantile/` — квантильная регрессия.
    - `Bayesian Reg/` — BayesRidge, ARD Regression.
  - `Discriminant Analysis/` — LDA vs PCA: код сравнения и иллюстрации разделимости.
  - `Support Vector Machines/` — SVM: ядра, границы решений, демонстрации.
  - `Ridge Kernel Reg/` — гребневая регрессия с ядрами.

Каждая из этих папок содержит свою краткую документацию (`Readme.md` или *.md файлы) и отдельные рабочие скрипты (`*.py`) с графиками (`*.png`).

### Как запускать примеры
- **Требования**: Python 3.10+ рекомендуется, а также следующие пакеты:
  - `scikit-learn`, `numpy`, `matplotlib` (и при необходимости `scipy`, `pandas`)
- **Установка окружения (пример):**
```bash
python -m venv .venv
. .venv/Scripts/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -U pip
pip install scikit-learn numpy matplotlib scipy pandas
```

- **Запуск конкретного примера:**
```bash
python "supervised-learning/Discriminant Analysis/LDA_vs_PCA.py"
```

- **Пример запуска линейной модели (Ridge):**
```bash
python "supervised-learning/linear/Ridge/ridge.py"
```

Большинство скриптов самодостаточны: они генерируют/загружают данные, обучают модель, выводят метрики и сохраняют визуализации рядом в виде `*.png`.

### Навигация по коду и документации
- **Корневой обзор:** этот README.
- **Тематические обзоры:** в каждой подпапке есть собственный `Readme.md` с краткой теорией, ссылками и пояснениями.
- **Код примеров:** по одному или нескольким `*.py` файлам на метод, снабжённым графиками и, где уместно, отчётами по качеству.

### Чем этот проект будет полезен работодателю
- Быстрое понимание моих практических навыков в классическом ML.
- Наличие самостоятельных примеров с пояснениями и визуализациями.
- Широкий охват: от базовых линейных методов до регуляризации, байесовских подходов, SVM и анализа признакового пространства.

Если вам нужно показать пример по конкретной теме — ориентируйтесь на соответствующую папку: в каждой директории есть своя документация и собственный код, который можно запустить и получить воспроизводимые результаты.
