# PyTorch Learning Sandbox

Учебный репозиторий с мини‑примеров по PyTorch: от тензоров и автодиффа до простых нейросетей, трансфер‑ленинга и сегментации (U‑Net). Цель — показать базовые навыки работы с PyTorch, понимание тензорной алгебры, датасетов/даталоадеров, построение моделей и тренировочных циклов.

## Что здесь есть
- **Тензоры и операции**: создание, типы, вью/ресшейпы, базовые арифметические операции, работа на CPU/GPU.
  - `tensors_intro.py`, `tensors_funcs.py`, `tensors_indexes.py`, `tensors_vectorMatrix.py`, `tensors_operations.py`, `tensors_cpu_gpu.py`
- **Автограф и backward**: эксперименты с автодифференцированием и вычислением градиентов.
  - `tensors_autocomp.py`, `backward.py`
- **Оптимизация / SGD**: черновик аппроксимации линейной модели и подготовки параметров.
  - `sgd_aproximate.py` (помечен как not completed)
- **Кастомные модули / слои**:
  - `linModule.py` (собственные заготовки/эксперименты с модулями)
- **Рекуррентные сети**: RNN для текста с собственным `Dataset` (набросок предобработки), демонстрация использования `torch.nn.RNN`.
  - `recurrentNN.py`
- **Трансфер‑ленинг**: перенастройка `resnet50` под 10 классов (заморозка фичей, замена `fc`).
  - `transfer_learning.py`
- **Сегментация (U‑Net)**: реализация UNet с энкодером/декодером, `SoftDiceLoss`, подготовка `Dataset` под маски, цикл обучения и инференс на изображении.
  - `unet_segment.py`
- **Вариационный автоэнкодер (VAE)**: MLP‑VAE с расчётом KL‑дивергенции и реконструкции.
  - `varAutoEnc.py`
- **Утилиты и заготовки**: работа с данными, блоки RNN, другие учебные наброски.
  - `dataManage.py`, `dualRecurent.py`, `balanceRepresentative.py`, `getting_started.py`
- **Colab**: шаблон для монтирования Google Drive в колабе.
  - `Colab Notebooks/templates/upload_drive.ipynb`

> Репозиторий носит учебный характер: часть файлов — минимальные демо/наброски, не все скрипты предназначены для «боевого» запуска без адаптации.

## Навыки, которые демонстрируются
- **PyTorch Core**: создание и преобразования тензоров, broadcasting, in‑place операции, работа с типами и устройствами (CPU/CUDA).
- **Autograd**: вычисление градиентов, понимание `requires_grad`, параметров и обновлений.
- **Torch NN**: сборка моделей из модулей (`nn.Module`, `Sequential`), линейные и рекуррентные блоки, инициализация и заморозка весов.
- **Datasets/DataLoaders**: базовые датасеты под изображения и маски, подготовка к батчингу и аугментациям.
- **Тренировочные циклы**: оптимизаторы (`RMSprop`), функции потерь (`BCEWithLogitsLoss`, `SoftDiceLoss`, KL‑дивергенция для VAE), логи обучения.
- **Computer Vision**: 
  - трансфер‑ленинг с `torchvision.models.resnet50`
  - сегментация U‑Net: энкодер/декодер, skip‑соединения, ConvTranspose2d, Dice‑метрика
  - базовые преобразования `torchvision.transforms.v2`

## Быстрый старт
1) Клонирование и окружение
```bash
git clone <repo_url>
cd pytorch
python -m venv .venv
.venv\Scripts\activate  # Windows PowerShell
pip install -U pip
pip install -r requirements.txt  # см. ниже, если файла нет
```

2) Проверка PyTorch
```bash
python - << "PY"
import torch
print("PyTorch:", torch.__version__)
print("CUDA available:", torch.cuda.is_available())
PY
```

3) Запуск простых демо
```bash
python tensors_intro.py
python tensors_operations.py
python tensors_cpu_gpu.py
python recurrentNN.py
```

4) U‑Net обучение (потребуется локальный набор данных)
- Подготовьте структуру датасета:
```
./dataset_seg/
  images/   # RGB изображения
  masks/    # однослойные маски (grayscale); фон=0, объект=1 (или инверсия в коде)
```
- Запустите обучение:
```bash
python unet_segment.py
```
Скрипт сохранит веса в `model_unet_seg.tar` и покажет пример инференса для `car_1.jpg`.

5) Трансфер‑ленинг ResNet50
```bash
python transfer_learning.py
```
Скрипт создаёт `resnet50` с замороженными фичами и заменённой головой под 10 классов (пример шаблона, данные не подгружаются).

Опционально: `jupyter`/`ipykernel` для запуска ноутбуков, `scikit-image`/`opencv-python` для CV‑экспериментов.

## Примечания по коду
- Код намеренно «учебный»: встречаются наброски и неполные примеры (`sgd_aproximate.py`), фрагменты исследований, минимальные демо без CLI/конфига.
- В файле `unet_segment.py` реализован полный проход: `Dataset`, модель UNet, две функции потерь (BCE + SoftDice), цикл обучения, сохранение и загрузка весов, инференс с визуализацией.
- В `varAutoEnc.py` представлен классический VAE‑лосс (MSE/SE + KL‑дивергенция) и репараметризация.
- В `transfer_learning.py` — пример правильной заморозки весов и замены `fc` для изменения числа классов.
