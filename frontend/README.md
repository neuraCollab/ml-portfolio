# ML Portfolio Frontend

React 18 + TypeScript + Vite + Tailwind CSS interface for the AutoTopic and RL Car Autopilot projects.
Originally prototyped in Google AI Studio as a static mock; now wired to the FastAPI backend in `../backend`.

See the [repository README](../README.md) for full setup, architecture, and API docs.

## Run locally

```bash
npm install
cp .env.example .env.local   # point VITE_API_BASE_URL at your backend if not localhost:8000
npm run dev
```
